# Strumenti del terminale

Il modulo installa gli helper della shell e il blocco gestito nel file di inizializzazione dell’utente, conservando il contenuto estraneo al progetto. I dati e i cataloghi sono condivisi con gli altri componenti; gli helper non duplicano l’aiuto dei programmi che avviano.

Il dispatcher `os` è implementato in Lua e distribuito come bundle validato. Alcuni helper e installer storici sono ancora Bash: il rapporto di migrazione li deve continuare a conteggiare fino alla sostituzione effettiva.

# Nautilus

Nautilus è l’unico gestore grafico dei file e usa GVFS per i dispositivi e le risorse supportate. Le impostazioni native preferiscono una lista compatta, cartelle prima dei file, anteprime e ricerca locali e apertura con doppio clic. I dialoghi GTK e l’integrazione con gli archivi restano nativi.

La configurazione usa GSettings e i dati applicativi del progetto. Conserva segnalibri personali e impostazioni estranee al modulo. L’apertura dei progetti nell’editor usa Zed; nessun collegamento deve riattivare i gestori dei file ritirati.

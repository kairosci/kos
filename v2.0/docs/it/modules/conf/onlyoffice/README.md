# OnlyOffice

OnlyOffice gestisce i documenti d’ufficio. Il componente Lua aggiorna il file INI nativo conservando sezioni e valori personali non gestiti, comprese le informazioni dell’account. L’installazione non sostituisce l’intero profilo.

I documenti si aprono nell’interfaccia a schede. I PDF restano associati a Papers. Percorsi, opzioni e destinazioni sono dichiarati nel registro applicativo e applicati tramite `make setup`.

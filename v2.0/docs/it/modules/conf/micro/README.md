# Micro ritirato

Micro non è più l’editor gestito. La configurazione personale e i plugin esistenti vengono conservati nell’archivio previsto dalla procedura di ritiro. Non vengono riattivati collegamenti, launcher o associazioni obsolete.

Zed è l’editor grafico; Neovim con il LazyVim distribuito dai pacchetti è l’editor del terminale. Il ritiro non autorizza la cancellazione dei documenti dell’utente.

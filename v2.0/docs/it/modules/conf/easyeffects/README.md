# EasyEffects

Il preset OS Subwoofer aggiunge armoniche alle basse frequenze senza pretendere di modificare le capacità fisiche degli altoparlanti. Prevede margine in ingresso, un filtro passa-alto a 60 Hz, elaborazione armonica sotto 110 Hz e un limitatore con soglia di −2 dB. Non garantisce l’assenza di distorsioni a ogni volume o su ogni dispositivo.

L’installazione conserva un preset esplicitamente scelto dall’utente, lo stato di mute, il dispositivo audio e gli effetti del microfono. Le copie dei dati personali hanno permessi privati. Le impostazioni del preset appartengono ai dati del componente; la verifica deve usare la versione nativa supportata, inclusa la compatibilità con EasyEffects 8.2.9.

# Zed

Zed è l’editor grafico predefinito. Il tema usa gli override nativi `theme_overrides` nelle impostazioni, aggiornabili nella stessa istanza in esecuzione; non dipende da temi personalizzati caricati soltanto all’avvio.

Il componente preserva le impostazioni personali estranee alla policy. La pianificazione delle risorse è calcolata dal componente Lua delle prestazioni usando budget e destinazioni dichiarati nei dati. Neovim rimane l’editor del terminale; Micro è ritirato con conservazione della configurazione personale.

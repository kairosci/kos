# Brave Origin

Brave Origin è il browser predefinito. Il componente installa le opzioni native e l’integrazione con il tema usando le destinazioni dichiarate nei dati applicativi. Riutilizza la directory del profilo esistente; non sostituisce database, password, sessioni o preferenze personali con copie statiche del repository.

Le modifiche gestite vengono riconciliate tramite `make setup`. La sincronizzazione della palette aggiorna i soli elementi di competenza del progetto, senza ricreare il profilo del browser.

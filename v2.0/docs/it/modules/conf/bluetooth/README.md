# Bluetooth

La personalizzazione della shell interroga BlueZ per rilevare gli adattatori disponibili, con un tempo massimo di due secondi. Un adattatore apparso dopo l’avvio resta rilevabile: un risultato iniziale vuoto non disabilita definitivamente la funzione.

La trasformazione richiede la versione attesa dei sorgenti nativi e rifiuta strutture non riconosciute prima di pubblicare il clone. I sorgenti installati dal gestore dei pacchetti restano in sola lettura. L’app Impostazioni riunisce i controlli Bluetooth con rete e audio; non occorre modificare manualmente i file di configurazione.

# Configurazioni delle applicazioni

Ogni directory possiede la configurazione di una funzione applicativa. Il registro Lua dichiara identità, destinazioni e opzioni dei componenti migrati; gli installer storici restanti sono ancora elencati dal rapporto di migrazione. Tutti vengono applicati attraverso la pipeline privilegiata, operando come utente reale quando necessario.

La configurazione conserva profili, sezioni INI, segnalibri e preferenze personali non gestite. Una sola applicazione svolge ciascuna funzione: Nautilus per i file, Zed per l’editor grafico, Neovim per il terminale, Papers per PDF, Loupe per immagini e Celluloid per i media. Impostazioni riunisce i controlli del desktop senza richiedere un ambiente GNOME completo.

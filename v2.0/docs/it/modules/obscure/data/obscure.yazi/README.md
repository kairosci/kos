# Plugin Yazi storico

Il plugin appartiene al sottoprogetto di protezione delle anteprime, ma Yazi non è più un’applicazione gestita. Il codice resta storico e non deve essere installato o abilitato dalla configurazione corrente.

Il mascheramento delle anteprime non impedisce l’accesso ai file e non sostituisce la cifratura o il blocco della sessione. Preservare eventuali configurazioni personali durante il ritiro. Non trasferire segreti attraverso ambiente o riga di comando.

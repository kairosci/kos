# Desktop health and interface

`make setup SCOPE=desktop-health` reconciles the missing EasyEffects package, the DNS health service and the keyboard helper through the privileged pipeline. It first publishes compatible runtime helpers, then performs a full package upgrade, preserving the distribution update contract. It does not change the bootloader. On this workstation all 145 live verification checks passed after reconciliation.

The keyboard verification failure was an API mismatch between the repository helper using `locale_init` and the installed translation runtime using `i18n_init`. The keyboard itself was already at its hardware maximum. Publishing the matching helper and catalog runtime fixes the check without inventing hardware success. Installed session, preview and desktop cleanup helpers are reconciled with the same translation API.

HyprMod interface policy is JSON in `modules/conf/hyprmod/data/interface.json`. Its application stylesheet, symbolic icon mapping and exact source patch live beside it. The patch targets the pinned application source and refuses drift without fuzzy matching. Layout changes are installed into a versioned environment, leaving the previous environment available. Navigation collapses below the policy breakpoint, opens the selected content and retains native back navigation. Initial selection follows the actual schema page rather than accidentally selecting the first pinned utility page. Page width, margins and spacing are shared across settings sections. Auto-save is seeded only when the user has not stored a preference; existing preferences and compositor configuration remain authoritative.

GTK palette policy lives in `modules/conf/gtk/data/palette.css.in`. The theme hook substitutes validated palette colors and retains native control geometry instead of globally removing all radii, shadows, backgrounds and spacing. Selection, focus, scrollbar safety and short color-only transitions remain explicit. User CSS is preserved. This improves the shared base for GTK applications and dialogs; it does not rewrite every application's own interface. Qt, Electron and web applications retain their own layouts.

`make setup SCOPE=interface` updates GTK and HyprMod without loading the audio preset or restarting audio and desktop services. `PREVIEW_INTERFACE=1` additionally opens HyprMod for visual review. Existing GTK applications may need reopening to load the new stylesheet. The native sources remain read only.

Calendar, weather and clock open as normal applications from Desktop tools. Settings is one application in Apps, without a duplicate tools submenu; it groups network, Bluetooth and audio controls. The desktop clock widget is disabled by policy and its installed plugin retired. `make setup SCOPE=desktop-tools` provisions the application package list and reconciles the session. No secondary notification daemon, locker or bar is introduced.

The shared user configuration installer publishes complete files through atomic replacement. Desktop tools run the same live session validation as the dedicated session scope. Calendar, weather, clock and the other controls launch native application windows from the localized menu. The previous clock layer is disabled. Resources uses its packaged `net.nokyan.Resources.desktop` identity.

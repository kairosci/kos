# OnlyOffice

OnlyOffice prend en charge les documents bureautiques. Le composant Lua met à jour le fichier INI natif en conservant les sections et valeurs personnelles non gérées, notamment les informations du compte. L’installation ne remplace pas le profil complet.

Les documents s’ouvrent dans une interface à onglets. Les PDF restent associés à Papers. Les chemins, options et destinations sont déclarés dans le registre applicatif et appliqués par `make setup`.

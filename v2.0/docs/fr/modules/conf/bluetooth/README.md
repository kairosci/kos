# Bluetooth

La personnalisation du shell interroge BlueZ pour détecter les adaptateurs disponibles, avec un délai maximal de deux secondes. Un adaptateur apparu après le démarrage reste détectable : un premier résultat vide ne désactive pas définitivement la fonction.

La transformation exige la structure attendue des sources natives et refuse les versions inconnues avant de publier le clone. Les sources du gestionnaire de paquets restent en lecture seule. L’application Paramètres regroupe Bluetooth, réseau et audio ; aucune modification manuelle des fichiers n’est nécessaire.

# Énergie

La personnalisation de l’indicateur supprime l’heuristique signalant une recharge lente tout en conservant les états pertinents, comme l’attente ou une charge complète sous 99 %. Elle ne modifie pas la limite matérielle de charge à 75 %.

Le rétroéclairage du clavier utilise le maximum réellement exposé par le périphérique, avec vérification en lecture. Les services respectent la restauration native de systemd et l’extinction avant l’hibernation ; ils ne touchent ni à l’écran ni aux voyants de verrouillage. Une interface absente est déclarée non prise en charge, jamais appliquée avec succès.

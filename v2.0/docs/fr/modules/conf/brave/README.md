# Brave Origin

Brave Origin est le navigateur par défaut. Le composant installe les options natives et l’intégration du thème aux destinations déclarées dans les données applicatives. Il réutilise le profil existant sans remplacer les bases de données, mots de passe, sessions ou préférences par des fichiers statiques du dépôt.

Les modifications gérées sont réconciliées par `make setup`. La synchronisation de la palette ne met à jour que les éléments appartenant au projet, sans recréer le profil du navigateur.

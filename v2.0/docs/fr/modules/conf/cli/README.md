# Outils du terminal

Le module installe les assistants du shell et le bloc géré dans le fichier d’initialisation de l’utilisateur en conservant le contenu personnel. Les données et catalogues sont partagés avec les autres composants ; les assistants ne recopient pas l’aide des programmes lancés.

Le répartiteur `os` est implémenté en Lua et distribué sous forme de paquet validé. Certains assistants et installateurs historiques utilisent encore Bash : le rapport de migration doit les compter jusqu’à leur remplacement effectif.

# Zed

Zed est l’éditeur graphique par défaut. Le thème utilise les `theme_overrides` natifs dans les paramètres, actualisables dans l’instance en cours ; il ne dépend pas de thèmes personnalisés chargés uniquement au démarrage.

Le composant conserve les préférences personnelles hors de sa politique. Les ressources sont calculées par le composant Lua de performance à partir des budgets et destinations déclarés dans les données. Neovim reste l’éditeur du terminal ; Micro est retiré avec conservation de sa configuration.

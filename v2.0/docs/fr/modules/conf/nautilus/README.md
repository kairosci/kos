# Nautilus

Nautilus est l’unique gestionnaire graphique de fichiers et utilise GVFS pour les périphériques et ressources pris en charge. Les réglages natifs privilégient une liste compacte, les dossiers en premier, les aperçus et la recherche locaux ainsi que le double clic. Les dialogues GTK et l’intégration des archives restent natifs.

La configuration utilise GSettings et les données applicatives du projet. Elle conserve les favoris personnels et les paramètres étrangers au module. Les projets s’ouvrent dans Zed ; aucun raccourci ne doit réactiver les gestionnaires retirés.

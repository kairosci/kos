# Configurations des applications

Chaque répertoire possède la configuration d’une fonction applicative. Le registre Lua déclare les identités, destinations et options des composants migrés ; les installateurs historiques restants figurent toujours dans le rapport de migration. Tous passent par la procédure privilégiée et utilisent l’identité réelle de l’utilisateur lorsque nécessaire.

La configuration conserve les profils, sections INI, favoris et préférences non gérés. Une seule application remplit chaque fonction : Nautilus pour les fichiers, Zed pour l’éditeur graphique, Neovim pour le terminal, Papers pour les PDF, Loupe pour les images et Celluloid pour les médias. Paramètres regroupe les contrôles du bureau sans installer un environnement GNOME complet.

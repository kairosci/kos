# Retrait de Micro

Micro n’est plus l’éditeur géré. La configuration personnelle et les extensions existantes sont conservées dans l’archive prévue par la procédure de retrait. Les anciens raccourcis, lanceurs et associations ne sont pas réactivés.

Zed est l’éditeur graphique ; Neovim avec le LazyVim distribué par les paquets est l’éditeur du terminal. Ce retrait n’autorise pas la suppression des documents personnels.

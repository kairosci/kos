# Agents

La configuration désactive le fournisseur Claude géré par le projet en conservant les autres fournisseurs et les préférences personnelles. L’installation passe par `make setup` ; elle n’ajoute ni widget ni service autonome. Les paramètres des agents restent distincts du moteur du bureau et n’autorisent pas de commandes privilégiées en dehors de cette procédure.

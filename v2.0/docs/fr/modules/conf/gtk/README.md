# GTK et palette

Le hook GTK applique la palette sélectionnée à GTK et libadwaita après chaque changement de thème. Materia fournit la base ; la surcouche Qogir utilise exactement l’accent du thème. Les contrôles compacts et plats distinguent sélection, focus et désactivation. Les durées d’animation appartiennent aux données de politique.

Les dialogues natifs de fichiers et d’applications restent fonctionnels. L’intégration ne réécrit pas les styles privés de chaque application : une maquette HTML ne prouve pas le comportement du toolkit installé. Les ressources Nerd Font 3.5.1 conservent leur provenance et leurs licences. Les modifications passent par la procédure d’installation ; un thème choisi explicitement prévaut sur le mode sombre initial.

# Retrait facultatif des outils d’IA

Ce sous-projet historique exige un choix explicite. Sans option, il affiche le plan ; l’exécution privilégiée nécessite `--yes`. La procédure principale ne doit pas l’atteindre indirectement depuis le retrait des paquets.

La politique concerne les observateurs de crash, les intégrations d’agents et les lanceurs d’IA autonomes. Elle ne retire ni les outils CLI gérés par mise, ni Tensaku, éditeurs, shell ou thèmes. Les opérations utilisateur nécessitent son véritable bus de session. Toute modification réelle effectuée par un agent passe par la procédure privilégiée et conserve les données personnelles.

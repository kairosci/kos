# Ancienne extension Yazi

Cette extension appartient au sous-projet de protection des aperçus, mais Yazi n’est plus une application gérée. Les sources restent historiques et ne doivent pas être installées ou activées par la configuration actuelle.

Le masquage des aperçus n’interdit pas l’accès aux fichiers et ne remplace ni chiffrement ni verrouillage de session. Les configurations personnelles sont conservées lors du retrait. Aucun secret ne doit transiter par l’environnement ou la ligne de commande.

# Session configuration

The session module owns the user Hyprland Lua configuration and the Quickshell menu opened with Super+Space. It retains the packaged compositor defaults, theme, input settings and autostart through an OS adapter outside the Hyprland configuration directory. Personal Lua settings are transformed rather than replaced. Unknown runtime references or invalid Lua stop installation before live files change. Managed block history is JSON data under the OS state directory, with a one time conversion and retirement of the previous Lua state format.

The module separates configuration in `data/`, transformations and installers in `scripts/`, and interface components in `qml/`. The menu width, control catalogue, bindings and shell defaults are read from JSON files. Generated runtime data lives under `${XDG_DATA_HOME:-$HOME/.local/share}/os/session/data/`. The menu reads that data directly; application entries come from Quickshell's desktop entry index with hidden entry filtering and desktop aware launching through `uwsm-app` and `gtk-launch`.

The normal menu width is 400 logical units, with the native screen bounds, palette, typography and larger capture and font menus preserved. Learn and the bar configuration routes are excluded from both packaged and personal menu data. Controls contains audio, network, Bluetooth, display, power, calendar, weather, media, tray applications, notifications, updates, workspaces and keyboard functions. Super+Shift+Space opens Controls; Super+Ctrl+1 through Super+Ctrl+9 address the media, audio, network, Bluetooth, display, power, calendar, weather and tray panels respectively.

The active bar option has no window or surface. Native panel content is adapted to independent popups without loading a hidden bar or reserving a screen edge. The old menubar configuration module is retired. Original shell preferences are saved in the OS state directory before migration, and calendar and other panel preferences move into their plugin entries. Media continues to use the locally owned OSMP sources. Quickshell's default path is configured with `QS_CONFIG_PATH` in the compositor, user manager, environment directory and supported shell startup files, so the default command addresses the existing native shell rather than starting another instance through a differently named configuration.

Run `make setup SCOPE=session` to reconcile this module through the privileged pipeline. It validates every staged Lua file, parses generated QML, compiles components in a separate validator that creates no desktop windows, and runs Hyprland's configuration verifier before installing files. It checks the compositor before restarting Quickshell when its inputs changed or its API is unavailable. Runtime verification requires a populated Apps model, the expected root menus, every standalone panel, the absence of a bar surface and the default IPC path. Reapplying unchanged inputs checks the same running shell without restarting it. The root update hook regenerates adapters from the installed package and reapplies this policy; packaged runtime files remain read only.

# Session configuration

The session module owns the user Hyprland Lua configuration and the Quickshell menu opened with Super+Space. It retains the packaged compositor defaults, theme, input settings and autostart through an OS adapter outside the Hyprland configuration directory. Personal Lua settings are transformed rather than replaced. Unknown runtime references or invalid Lua stop installation before live files change. Managed block history is JSON data under the OS state directory, with a one time conversion and retirement of the previous Lua state format.

The module separates configuration in `data/`, transformations and installers in `scripts/`, and interface components in `qml/`. The menu width, control catalogue, bindings and shell defaults are read from JSON files. Source indexed message catalogues live in `data/locales/` for the six supported languages, and generated runtime data lives under `${XDG_DATA_HOME:-$HOME/.local/share}/os/session/data/`, including the resolved `translations.json`. The menu reads that data directly; application entries come from Quickshell's desktop entry index with hidden entry filtering and desktop aware launching through `uwsm-app` and `gtk-launch`. Display bindings in generated QML resolve through the `SessionI18n` singleton, which keeps application, media and user content untouched while routing dates through the resolved locale.

The normal menu width is 800 logical units, with native screen bounds, palette and typography preserved. Learn and the bar configuration routes are excluded from both packaged and personal menu data. The menu launches applications; system configuration lives in GNOME Settings, which is provisioned with default opacity tiling and a dedicated shortcut instead of popup panels. The retired Controls subtree, its panels, shortcuts and installed copies are removed on setup.

The menu plugin carries no bar surface. The old menubar configuration module is retired. Original shell preferences are saved in the OS state directory before migration. Quickshell's default path is configured with `QS_CONFIG_PATH` in the compositor, user manager, environment directory and supported shell startup files, so the default command addresses the existing native shell rather than starting another instance through a differently named configuration. OS owned configuration lives under `~/.config/os`, with a compatibility link at the legacy native path so native commands keep working.

Run `make setup SCOPE=session` to reconcile this module through the privileged pipeline. It validates every staged Lua file, parses generated QML, compiles components in a separate validator that creates no desktop windows, and runs Hyprland's configuration verifier before installing files. It checks the compositor before restarting Quickshell when its inputs changed or its API is unavailable. Runtime verification requires a populated Apps model, the expected root menus and the default IPC path. Reapplying unchanged inputs checks the same running shell without restarting it. The root update hook regenerates adapters from the installed package and reapplies this policy; packaged runtime files remain read only.

The desktop clock is a service plugin with one noninteractive bottom layer surface per screen. It reserves no screen space and does not take keyboard focus or pointer input. Palette, font and spacing use native shell singletons. `data/policy.json` owns its enabled state, identifier, top-right anchor and minute display format. `data/clock-manifest.json` owns its service metadata; `qml/ClockWidget.qml` owns the interface. `scripts/clock.sh` uses an associative array and namespaced functions to model widget staging without executable policy or eval. The installer stages and validates it before installation, and session setup verifies a live clock layer. The menu width is 800 logical units, clamped to the screen by native layout.

# Session configuration

The session module owns the user Hyprland Lua configuration and the Quickshell menu opened with Super+Space. It retains the packaged compositor defaults, theme, input settings and autostart through an OS adapter outside the Hyprland configuration directory. Personal Lua settings are transformed rather than replaced. Unknown runtime references or invalid Lua stop installation before live files change. Managed block history is JSON data under the OS state directory, with a one time conversion and retirement of the previous Lua state format.

The module separates configuration in `data/`, transformations and installers in `scripts/`, and interface components in `qml/`. The menu width, control catalogue, bindings and shell defaults are read from JSON files. Source indexed message catalogues live in `data/locales/` for the six supported languages, and generated runtime data lives under `${XDG_DATA_HOME:-$HOME/.local/share}/os/session/data/`, including the resolved `translations.json`. The menu reads that data directly; application entries come from Quickshell's desktop entry index with hidden entry filtering and desktop aware launching through `uwsm-app` and `gtk-launch`. Display bindings in generated QML resolve through the `SessionI18n` singleton, which keeps application, media and user content untouched while routing dates through the resolved locale.

The normal menu width is 800 logical units, with native screen bounds, palette and typography preserved. Learn and the bar configuration routes are excluded from both packaged and personal menu data. The menu launches applications; system configuration lives in HyprMod, which is provisioned with default opacity tiling and a dedicated shortcut instead of popup panels. The retired Controls subtree, its panels, shortcuts and installed copies are removed on setup.

# Session configuration

The session module keeps the user Hyprland Lua files free of comments and explicit runtime branding while retaining the native compositor defaults, theme, input settings and autostart through an OS adapter outside the Hyprland configuration directory. Existing settings are transformed rather than replaced with static defaults. Unknown runtime references or invalid Lua stop the installation before live files are changed. Managed block state is stored separately so subsequent setup runs can update commentless configuration without duplicating policy.

The menu is a local clone of the installed native menu with its normal width increased from 300 to 360 logical units. The larger capture and font menus retain their native width, and screen bounds still constrain all menus. Native colors, fonts, spacing, animations and panel services remain unchanged. A localized Bar submenu provides visibility, settings and position controls. The bar starts hidden using the native visibility flag, while Super+Space still opens the menu and Super+Shift+Space toggles the bar.

Run `make setup SCOPE=session` to reconcile this module through the privileged pipeline. It validates every staged Lua file, runs Hyprland's configuration verifier and parses the customized QML before installing files. The pipeline reloads the compositor configuration and checks its reported errors before restarting Quickshell when menu content changed or its IPC is unavailable. Reapplying unchanged configuration checks the running menu without restarting it. A full setup runs the session stage after other configuration producers. The installed root update hook regenerates the local menu clone from the updated runtime and reapplies the same policy without restarting the shell.

Shared user configuration helpers retain backups beside changed files. The runtime package is read only; the adapter delegates to it rather than copying or replacing compositor defaults. The module preserves the existing monitor geometry, active theme, idle settings and personal menu extension entries.

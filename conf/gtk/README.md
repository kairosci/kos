# GTK

Setup installs flat GTK styling through the palette hook and native settings through this installer. GTK animations are enabled and client window buttons are disabled. Pointer hover, selected rows, text selections, checked controls and suggested actions retain distinct states. Scrollbar sliders preserve nonnegative geometry. Square controls, compact headerbars, outlined keyboard focus and palette selection remain visible in light and dark themes. Headerbars, sidebars, cards and dialogs share the palette background without raised surfaces.

Buttons use consistent control heights and separate hover, pressed and toggled states. Suggested actions retain the exact palette accent; toggled toolbar buttons use the selection color with an accent border. Entries show an accent caret and focus border. Tabs use a stable underline, boxed lists use fine separators, and unchecked controls retain a visible outline. Disabled buttons remain muted without an active accent fill.

All application windows use opaque, square surfaces without compositor shadows or blur. Windows, layers and popups fade in over 140 ms and fade out over 100 ms with a gradual easing curve. Only compositor opening and closing opacity transitions animate; focus, dimming, borders and layer geometry update immediately to avoid additional redraws during interaction. Workspace changes, including special workspaces, are immediate to avoid overlapping outgoing and incoming tiles. Window geometry updates immediately, avoiding animated paths that cross neighboring tiles. Tearing is explicitly disabled. OS's application animation exclusions and instant bar and panel layer rules remain authoritative.

The desktop uses the dwindle tiling layout with zero gaps and one pixel borders. Main windows tile; modal dialogs and windows tagged by OS as floating retain their dialog behavior. Keybindings are preserved. GTK keeps application controls and file dialogs functional, with flat palette colors and no client window buttons, gradients or rounded widgets.

Run `make setup` after merging the desktop PRs. Reopen libadwaita applications to load updated CSS. The installer preserves unrelated Hyprland configuration.

The Qogir overlay uses scalable outlines of the eza file and folder glyphs from JetBrainsMono Nerd Font 3.5.1. Folders follow the palette accent and MIME icons follow the foreground. Qogir retains application and action icons. Assets ship with setup and theme changes require no font rendering process or Python dependency. The font license is included with the source outlines.

GTK buttons, entries, dropdowns, rows, menu items, tabs, checks, radios, switches, sliders, links and expanders transition their colors and borders over 120 ms. Progress indicators use 140 ms and pressed states use 60 ms. CSS transitions exclude geometry, transforms and opacity, leaving container navigation and switch movement to their native toolkit. Disabled controls update immediately. Popup opening opacity remains owned by the compositor, so GTK adds no second fade. Turning off the desktop enable animations preference also disables toolkit animations. Electron applications retain their own internal animation behavior.
